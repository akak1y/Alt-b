# Alt

Тестовый веб-клиент Matrix. Браузер работает с Synapse напрямую через
`matrix-js-sdk`; локальный сервер только раздаёт собранные файлы из `public/`
и выставляет Content Security Policy (CSP). База данных, серверные маршруты
авторизации и Socket.IO для клиента не нужны.

## Запуск

Нужны Node.js 20 или новее и npm. Устанавливайте **все** зависимости, включая
зависимости для сборки:

```sh
npm ci
npm start
```

Откройте `http://localhost:3000/`. Порт можно изменить переменной окружения
`PORT` (например, `PORT=4000 npm start` в Unix-подобной оболочке).
`npm start` перед запуском сервера собирает клиент через esbuild. Для разработки
используйте `npm run dev`; на Windows доступна команда `npm run dev:win`.
После изменений исходников в режиме `dev:win` запускайте `npm run build`
повторно: этот режим не пересобирает клиент при перезапуске сервера.

В `public/index.html` находится шаблон интерфейса. Сборка в `build-client.js`
заранее компилирует его средствами Vue и объединяет код с `matrix-js-sdk`
в `public/js/alt.js`. Собранный файл не хранится в Git.

## Работа с Matrix

Адрес Synapse задан в `public/js/matrix-core.js`:
`https://synapse.creatusest.ru`. Логин, сессия, синхронизация комнат,
сообщения, приглашения и история обрабатываются в браузере. Данные сессии
хранятся в `localStorage`; CSP ограничивает источники скриптов и соединений.
Сквозное шифрование (E2EE) **не поддерживается**: для проверки переписки
используйте незашифрованную комнату. Регистрация по коду приглашения пока
имеет известное ограничение в обработке Matrix UIA (`completed` в ответе
Synapse), поэтому наличие формы регистрации не означает, что она работает.

`docker-compose.yml` описывает **только отдельный тестовый Synapse** с данными
в `matrix/data/`. Он не запускает Alt и не подменяет адрес Synapse,
закреплённый в клиенте; его настройка и данные не меняются при сборке Alt.
Переменная `MATRIX_SERVER_NAME` в `.env.example` относится только к этому
необязательному окружению. Сервер Alt читает `PORT` из окружения и не загружает
файл `.env` автоматически.

## Проверки

```sh
npm run check
```

Команда запускает Prettier, ESLint, сборку и тесты. Тесты проверяют клиент
на имитациях SDK/браузера; **реальное подключение к Synapse они не проверяют**.
