# Интеграция дизайна Alt

Интеграция выполнена от `main` (`0a7f645f6568eca18f6fe4015ff3e8b172cc6cb9`).
Визуальный источник — коммит Gubga в `design2`
(`ff69257bbe4c479f19806fdde32f16088cd33f6e`). Общий предок — `07c7983`.
[Исходный дизайн и авторство](https://github.com/akak1y/Alt-b/commit/ff69257bbe4c479f19806fdde32f16088cd33f6e)

## Что перенесено

- Палитра, шрифт, логотип, оформление авторизации и переписки. По итогам
  обсуждения оставили одну активную форму с переключателем «Вход» /
  «Регистрация». Ссылка с токеном сразу открывает регистрацию.
- Боковая панель, сворачиваемый список комнат, шапка, разные стили входящих
  и исходящих сообщений. На узком экране список комнат и переписка
  показываются по отдельности. История подгружается в ленту при прокрутке
  вверх с сохранением позиции. При ошибке в ленте доступен повтор.
- В меню вынесены темы, фон, анимации, выход из аккаунта, краткие экраны
  «О проекте» и «Разработка». Имена разработчиков оставлены в согласованном
  формате заглушек. Справка ALT отвечает на типовые вопросы локально.
- Canvas-фон включается по выбору пользователя. По умолчанию используется
  тёмная статика. Предпочтения хранятся в браузере, отрисовка приостанавливается
  в скрытой вкладке, а уменьшенное движение оставляет кадр статичным.

## Совместимость

В исходном дизайн-коммите шаблон блокировал отправку в зашифрованных
комнатах и не содержал управления регистрационными приглашениями. Новая
разметка использует обработчики `main` для E2EE, приглашений, входа,
восстановления и выхода. Код Rust Crypto, хранение его ключей, Web Locks,
CSP и проверки прав Express сохранены. Адаптация Matrix-слоя ограничена
возвращаемым признаком наличия предыдущей страницы истории.

Для личной ссылки создатель одноразового приглашения может указать логин.
Дополнение добавляется к URL во фрагменте, и получатель вводит только пароль.
Synapse проверяет токен и доступность логина. Имя в ссылке служит
предзаполнением формы, серверной привязки токена к логину нет. Обычные
ссылки с токеном поддерживаются. Персональную версию следует скопировать
из окна создания, в списке после повторного открытия остаётся базовая
ссылка Synapse.

Устаревшие `AGENTS.md`, `.github/copilot-instructions.md` и пустой файл
`npm` из `design2` исключены. Отдельные панели фоновых эффектов заменены
разделом общего меню. Списки внутренних файлов на пользовательских
экранах, эффект случайного сбоя логотипа и демонстрационная панель FPS
опущены.

## Проверки и оставшаяся работа

`npm run build` и `npm run check` прошли на исходном `main` и после каждого
этапа. Итоговый набор содержит 66 тестов, включая существующие проверки
Rust Crypto и API приглашений, а также новые проверки личных ссылок.
В Chromium (1366 и 390 px) с имитацией Matrix API проверены восстановление
сессии, история, личная ссылка, создание и отзыв приглашения, смена темы
и уменьшенное движение. В отдельном прогоне с настоящим WASM проверены
тип зашифрованного сообщения на проводе, расшифровка после перезагрузки,
блокировка второй вкладки и обычная отправка.

Ручная проверка с тестовыми аккаунтами на реальном Synapse и Element
остаётся перед выпуском. Сценарий описан в [архитектуре E2EE](E2EE_ARCHITECTURE.md).

Интеграция подготовлена одним PR с последовательными коммитами. Переходы
между экранами, меню, оформление чата и мобильная навигация используют
общий Vue-шаблон и палитру. Один PR позволяет проверить все варианты
состояния клиента вместе, сохраняя возможность ревью отдельных коммитов.
